# VideoRead

[![English](https://img.shields.io/badge/README-English-2d6cdf?style=for-the-badge)](README.md) [![简体中文](https://img.shields.io/badge/%E8%AF%B4%E6%98%8E-%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-2d6cdf?style=for-the-badge)](README.zh-CN.md)

VideoRead 是一个用于批量审阅视频的多窗口平铺播放器。

当前版本：`v0.9`

它适合这些场景：
- 同时查看多个短视频或片段
- 横屏与竖屏视频混合对比
- 保持顺序、比例与尽量高的屏幕利用率
- 用模板保存常用视频组合并重复打开
- 其实最大的作用是方便你用你巨大的屏幕，自动平铺各种你精选的小视频即刻起飞

## 本版本主要功能
- 多窗口组同时打开视频
- 默认静音循环播放
- 支持拖拽导入视频
- 固定行数排版与智能排版
- 组内拖动调整视频顺序
- 单视频悬浮控制：播放/暂停、静音、进度、音量
- 模板库、历史记录、会话保存
- 模板打开、更新、重新加载、删除
- 批量移除视频
- 系统播放模式与可选 VLC 播放模式

## v0.9 更新摘要
相比 v0.8，本版本主要增加和改进：
- 增加系统模式 / VLC 模式播放后端选择
- 增加单视频进度条，可在悬浮控制中独立调整播放进度
- 增加右键“全部重新开始播放”，方便做视频帧对比
- 增加窗口组内多选、取消选中和批量移除
- 增加窗口内右键保存模板、更新模板、重新加载模板等操作
- 优化横屏/竖屏混排排版和跨 DPI 屏幕移动后的重排表现
- 改进模板重新加载、移除视频时的播放器清理逻辑

## 下载与使用
仓库内已附带可直接运行的发布版：
- `dist/VideoRead.exe`

使用说明：
- 直接运行 EXE 不需要提前安装 Python
- 首次运行时，程序会在 `dist/state/` 下自动生成自己的本地状态目录
- 建议把整个 `dist` 目录一起保存和移动

播放说明：
- 常见 `mp4`、`mkv`、`webm`、`mov`、`avi` 文件可直接尝试播放
- 如果个别视频格式无法播放，优先尝试 `H.264 + AAC` 的 `mp4` 文件
- 系统模式会使用本机 Windows / Qt 多媒体环境
- 如果检测到兼容的 VLC / libVLC 运行库，可以在应用内切换 VLC 模式
- 如果 VLC 模式不可用，VideoRead 仍可继续使用系统模式

## 从源码运行
环境要求：
- Windows 10/11
- Python 3.12 或相近版本

安装依赖：
```powershell
python -m pip install -r requirements.txt
```

可选 VLC 模式：
- 可以在 Windows 上安装 VLC，或把兼容的 `libVLC/` / `vlc_runtime/` 文件夹放到 `app.py` 旁边。
- 源码仓库不包含本地运行库包，也不包含个人模板、历史记录或本地状态数据。

启动：
```powershell
python app.py
```

也可以双击：
- `start_videoread.bat`

## 基本使用
1. 启动程序后创建窗口组。
2. 拖拽视频到窗口组中，或使用界面按钮导入。
3. 根据需要切换固定排版或智能排版。
4. 鼠标移到单个视频上，会显示简洁悬浮控制条。
5. 在窗口组中拖动视频即可调整顺序。
6. 可保存为模板，下次直接打开常用视频组。

## 模板与历史
- 模板：适合保存常用视频组合、顺序、算法与排版设置。
- 历史：适合恢复最近的查看状态。
- 这些内容默认写到本地 `state/` 目录，不会改动原始视频文件。
